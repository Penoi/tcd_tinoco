Merge Sort

Merge Sort é um algoritmo de ordenação baseado na estratégia Dividir e Conquistar (Divide and Conquer). Ele divide o vetor em partes menores, ordena cada uma delas e, por fim, realiza a junção (merge) dessas partes de forma ordenada.

1. Como funciona?

O algoritmo segue três etapas:

  1. Divide o vetor em duas metades.
  2. Ordena cada metade recursivamente.
  3. Une as duas metades ordenadas.

5. Complexidade

Caso Tempo
Melhor O(n log n)
Médio O(n log n)
Pior O(n log n)
Memória O(n)

6. Vantagens

  • Complexidade garantida O(n log n).
  • Algoritmo estável.
  • Excelente para grandes conjuntos de dados.
  • Muito utilizado em processamento paralelo.

7. Desvantagens

  • Necessita memória auxiliar.
  • Mais lento que QuickSort em muitos casos práticos.
  • Implementação mais complexa.

8. Código C++



void mergeSort(vector& v,int l,int r){

    if(l>=r) return;

    int m=(l+r)/2;

    mergeSort(v,l,m);

    mergeSort(v,m+1,r);

    merge(v,l,m,r);

}

Resumo

O Merge Sort sempre divide o problema em partes menores, resolve cada parte individualmente e depois combina os resultados em ordem crescente.
